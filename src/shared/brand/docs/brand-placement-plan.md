# Brand Placement Plan

## جدول توزيع البراند

| الواجهة | موضع الظهور | الأصل المستخدم | الأولوية |
| --- | --- | --- | --- |
| Landing | أعلى الهيرو مع اسم Ordely | `ordely-logo.svg` | عالية |
| Auth | جانب القيمة أو أعلى النموذج | `ordely-logo.svg` | عالية |
| Admin | رأس اللوحة بجانب العنوان | `ordely-icon.svg` أو `ordely-logo.svg` حسب المساحة | عالية |
| Store | لا يظهر شعار Ordely كعلامة رئيسية حتى لا يزاحم هوية المتجر | `ordely-icon.svg` اختياري في حالات الخطأ فقط | منخفضة |
| Browser | favicon | `ordely-icon.svg` | عالية |

## قاعدة مهمة

المتجر العام يعرض هوية صاحب المتجر أولًا. براند Ordely يظهر في صفحات البيع الخاصة بالمنتج نفسه، وفي اللوحة كهوية أداة، وليس كبديل لهوية المتجر.
